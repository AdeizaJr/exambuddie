# ExamBuddie — Landing Page

Marketing site for [ExamBuddie](https://exambuddie.app). Built with Next.js 15 (App Router) + Tailwind CSS.

## Pages

| Route | Description |
|-------|-------------|
| `/` | Homepage — hero, features, pricing, FAQ |
| `/privacy` | Privacy Policy (NDPA 2023 compliant) |
| `/terms` | Terms of Use |
| `/refunds` | Refund Policy |

## Dev

```bash
npm install
npm run dev       # localhost:3000
npm run build     # production build
```

## Deploy

Deployed on Railway. Push to `main` triggers auto-deploy.
